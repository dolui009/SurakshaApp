# Suraksha+ Women Safety App 🚺🛡️

A comprehensive Android safety application designed to protect women in emergency situations.

## Features ✨

### 🆘 Emergency SOS
- One-tap SOS button
- Power button triple-press trigger
- Shake detection trigger
- Volume button trigger (configurable)

### 📍 Live Location Tracking
- Real-time GPS tracking
- Location sharing with trusted contacts
- Google Maps integration
- Location history

### 📹 Audio/Video Recording
- Automatic recording during SOS
- Secure encrypted storage
- Evidence preservation

### 📞 Communication
- Automatic SMS to emergency contacts
- Auto-dial primary contact
- Emergency services integration
- Offline SMS alerts

### 🕵️ Stealth Mode
- Calculator disguise
- Hidden from recent apps
- Secret SOS triggers
- Lock screen protection

### 👥 Trusted Contacts
- Manage 3-5 emergency contacts
- Priority-based notifications
- Contact verification

### 🚶 Safe Walk Mode
- Trip sharing
- Deviation alerts
- Inactivity detection
- "Reached Safely" notification

### 🗺️ Nearby Help
- Police stations
- Hospitals
- Safe places
- Real-time directions

### 📞 Fake Call
- Scheduled fake calls
- Custom caller identity
- Emergency escape tool

### 🔊 Loud Alarm
- High-decibel siren
- Vibration patterns
- Screen flashing
- Attention-grabbing

## Technical Stack 💻

- **Language:** Kotlin
- **Backend:** Firebase (Auth, Firestore, Realtime DB)
- **Maps:** Google Maps SDK
- **Location:** Google Fused Location Provider
- **Architecture:** MVVM
- **Min SDK:** 24 (Android 7.0)
- **Target SDK:** 34 (Android 14)

## Setup Instructions 🚀

### Prerequisites
- Android Studio Hedgehog or later
- Google Maps API Key
- Firebase Project
- Android device/emulator with API 24+
